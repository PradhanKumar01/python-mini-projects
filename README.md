# Simple Calculator (Python)

This is a menu-based calculator program made using Python.
It performs basic mathematical operations.

## Available operations
- Addition
- Subtraction
- Multiplication
- Division

## How to run
Open terminal in this folder and run:

python calculator.py

## Requirement
Python 3

# Guess Number Game (Python)

This is a small guessing game made using Python.
The computer selects a random number and the user has to guess it.

## Game rules
- Number is between 1 and 20
- Total attempts: 5
- Program gives hints (higher / lower)

## How to run
Open terminal in this folder and run:

python guess_number.py

## Requirement
Python 3

# Password Generator (Python)

This is a simple password generator program written in Python.
It creates a random password based on user choice.

## What this program does
- User enters password length
- User chooses letters, numbers, and symbols
- Program generates a random password

## How to run
Open terminal in this folder and run:

python password_generator.py

## Requirement
Python 3
